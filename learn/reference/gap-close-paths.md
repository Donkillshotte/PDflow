# Closing a live capability gap

1. Read the `GAP` reason in the current report.
2. Install or provide the named executable, model, or deck.
3. Set `PD_FLOW_RUN_DIR` for the complete workflow.
4. Rerun the affected stage with current artifacts.
5. Verify input fingerprints and report status.

Nangate45, ASAP7, and other PDK tracks have separate contracts. A sidecar
artifact can be inspected independently, but it cannot be mixed into a result
unless the report declares compatible geometry, libraries, constraints, and
mesh identity.
