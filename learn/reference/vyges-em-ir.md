# vyges-em-ir

`run_vyges_em_ir.sh` evaluates the current routed power network with the
current activity/current map. The report includes source paths, mesh identity,
solver status, and the worst observed quantity.

It is complementary to Dynamic IR: EM and IR use related inputs but answer
different questions. The Studio ledger keeps them as distinct current
artifacts. Missing models or executable produce `GAP`.
