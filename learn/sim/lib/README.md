# Sidecar liberty (not the ORFS Nangate drop)

`nangate45_ptm_ccs_sidecar.lib` is an educational CCS re-characterization of
GCD combinational cells (INV/BUF/NAND/NOR/AND) from the public PTM 45 nm
card + the ORFS CDL. `INV_X1_ptm45_ccs.lib` is the one-cell subset.

The official `NangateOpenCellLibrary_typical.lib` stays NLDM. Do not
replace it. Do not restamp gold Dynamic IR with this file.
