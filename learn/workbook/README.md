# Workbook

Use this workbook with the current local run. Copy paths and observations;
never fill an answer from a fixed metric table.

## Sections

- A — constraints and SDC;
- B — synthesis and mapped cells;
- C — floorplan and PDN;
- D — placement and CTS;
- E — routing and DRC;
- F — finish, GDS, SPEF and signoff;
- G — current-data review and reflection.

Templates: [`notes-template.md`](notes-template.md),
[`final-project-template.md`](final-project-template.md).
Questions: [`quiz.md`](quiz.md). Worked method: [`solutions.md`](solutions.md).
Data contract: [`../reference/live-analysis.md`](../reference/live-analysis.md).

For every exercise write:

1. command and environment;
2. run id and variant;
3. input and output paths;
4. status and the observation;
5. one limitation or unavailable dependency.

The GUI reference is [`../reference/gui-atlas.md`](../reference/gui-atlas.md).
