# NangateOpenCellLibrary.v

Behavioral Verilog for the **Nangate Open Cell Library 45 nm** (same library
ORFS already ships as Liberty / LEF / GDS). Used only for **functional**
gate-level simulation (Icarus). Not SDF, not CCS, not a foundry kit.
